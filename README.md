# X 实时翻译

Android 10（API 29）及以上；目标 API 34。包名 `com.xlivetranslate.app`。

## 安装

产物为项目根目录的 `x-live-translate-debug.apk`，是开发用 debug 签名版本。

电脑连接手机、开启 USB 调试后执行：

```sh
adb install -r x-live-translate-debug.apk
```

也可把 APK 传到手机，允许文件管理器“安装未知应用”，点击安装。相同包名但不同签名的旧版需先卸载，卸载会清空模型和设置。

## 授权与首次准备

1. 打开 App，点击“授予悬浮窗权限”，在系统页允许显示在其他应用上层。
2. 点击“授予麦克风与通知权限”。内部音频捕获同样需要 RECORD_AUDIO 权限；Android 13 以上另有通知权限。通知被禁用时可通过“通知系统设置”开启，建议允许以便随时停止。
3. 点击“下载英文小模型”。约 40 MB，解压后保存在应用私有目录；主界面显示下载百分比、解压或失败原因。下载期间请保持 App 在前台，进程被杀后重新点击会从头下载。不在构建过程中下载或内置模型资产。
4. 设置翻译引擎。默认 ML Kit 首次翻译自动下载英、中离线模型，需要网络；模型就绪后可以离线翻译。首次下载可能较慢，最长等待约 120 秒，失败会显示中文错误。
5. 点击开始，内部音频模式会每次弹出系统录屏/音频捕获授权。允许捕获；若系统提供“整个屏幕”选项，建议选整个屏幕后打开 X。本 App 仅创建音频录制器，不保存屏幕图像。

## 使用

开始后切到 X，播放英文视频。悬浮窗显示识别中的英文和句末的中文译文；英文识别与中文翻译存在时间差。拖动悬浮窗标题移动字幕；A−/A+ 调整本次会话字号；隐藏按钮开关字幕显示，控制栏保留；停止按钮结束服务，也可从通知或主界面停止。

设置中可保存默认字号（12–36）、背景不透明度（20–100）、音频来源和翻译引擎。更改设置后请停止再开始。识别引擎固定为 Vosk 离线英语，本版本未实现可选的云端语音识别或 Gemini 翻译。

内部音频持续约 10 秒低于阈值时，悬浮窗和通知会提示视频可能静音或目标 App 不允许捕获。点击悬浮窗“麦克风”打开主界面，再点击“切换到麦克风模式并开始”；也可停止服务后在设置选择麦克风，再开始。此流程让 App 在前台启动麦克风服务，符合 Android 的后台限制。麦克风模式不申请录屏授权，需要外放视频声音，会收录周围环境声音，戴耳机时通常无法识别视频。

## 自定义 API

设置中选择“OpenAI 兼容 API”，填写：

- API Base URL：必须为 HTTPS，一般包含 `/v1`，例如服务商提供的兼容 API 根地址；App 追加 `/chat/completions`。
- 模型名称：填写服务商支持的聊天模型标识。
- API Key：填写自己的密钥；无需认证的接口可留空。

代码未内置密钥。密钥存放在应用私有普通 SharedPreferences，关闭系统备份；未额外加密。不要在共用设备输入敏感密钥。使用云端翻译时，识别出的英文文本会发送到用户填写的服务端；录音不上传，也不保存音频文件。费用和可用性取决于服务商。HTTP 错误、无效响应、超时都会在字幕/主界面显示，不会自动改用其他翻译服务。没有配置 API 时可以使用默认 ML Kit。

## 模型源及大陆网络

默认官方下载源：

`https://alphacephei.com/vosk/models/vosk-model-small-en-us-0.15.zip`

设置支持自定义 HTTPS 镜像 ZIP URL；优先尝试自定义地址，网络下载失败后尝试官方地址（相同地址只试一次）。本项目不声称提供或验证了第三方镜像。可填写自行托管的相同模型压缩包地址；镜像内容的来源和可信度由使用者确认。解压限制路径、体积，检查模型结构并尝试加载后才安装。不支持断点续传、下载校验和或登录式下载链接；解压/校验失败会报错，需要更换地址重试。重新下载仅在停止翻译后可用。

大陆网络可能无法访问 Vosk 官方站或 Google 模型服务。ML Kit 的模型下载依赖 Google 相关模型分发服务，具体设备和网络下可能失败；不能承诺无 Google 服务的手机可用。请使用可访问的自定义模型 HTTPS 镜像，以及大陆可用、支持 OpenAI 聊天协议的翻译服务。联网只有模型下载与所选 API 请求；Vosk 安装后离线识别。

## 构建

```sh
source /home/box/tools/env.sh
./gradlew assembleDebug
cp app/build/outputs/apk/debug/app-debug.apk x-live-translate-debug.apk
```

JDK 17，Gradle wrapper 8.7，Android Gradle Plugin 8.5.2，Kotlin 1.9.24，compileSdk/targetSdk 34，minSdk 29。`local.properties` 指向 `/home/box/tools/android-sdk`，换机器需修改。依赖由 Gradle 从 Google Maven/Maven Central 下载。未将模型等额外二进制资产下载到仓库。

- X 是否允许捕获音频需真机实测。目标应用可以通过 `allowAudioPlaybackCapture`、播放器捕获策略、usage 或受保护内容限制录制；本 App 无法绕过。相关系统限制见 [Android 音频捕获文档](https://developer.android.com/media/platform/av-capture)。
- 悬浮窗权限、录屏授权、Android 14 前台服务、通知、麦克风、拖动及显示、模型下载/解压/加载、ML Kit 模型下载和翻译、自定义 API 调用、静音检测与资源释放目前均只有源码实现和编译检查，未经设备端验证。
- 使用 AudioRecord 请求 16 kHz、单声道、16 位 PCM，由 Android 音频框架提供转换；未实现独立软件重采样器。如果设备拒绝该格式，会提示错误并停止。需要在具体设备验证兼容性。
- 静音检测为平均绝对振幅阈值启发式，无法区分真正的静音、没有播放、音量低、权限问题或应用禁止捕获，可能误报。
- 句末由 Vosk 语音端点检测决定；长时间连续说话可能延迟翻译。部分英文每约 250 ms 更新；翻译队列最多等待一个句子，跟不上时丢弃较旧等待任务，过期译文不覆盖新句子。无逐词对齐和历史字幕功能。
- 英文小模型对口音、音乐、多人同时说话和噪声准确率有限。翻译速度取决于手机性能、首次模型下载和 API 网络；不能承诺低延迟。
- 模型下载在进程内线程执行，退出进程会中断；捕获服务不自动重启，系统终止、用户撤销录屏或停止服务后需重新开始并授权。
- 后台保活、锁屏、多窗口、不同厂商省电限制、旋转屏幕、Android 15/16、原生库较新设备的页大小兼容性未验证。此 APK 为原型 debug 版本，不代表已满足商店发布要求。
